The Challenge

Laboratory experiments in pharmaceutical environments frequently experience delays caused by equipment degradation, reagent quality issues, scheduling conflicts, and resource bottlenecks.

These delays create operational inefficiencies that affect planning, resource allocation, and laboratory productivity.

The objective of this project was to predict, at booking time, whether an experiment was likely to experience a delay of 30 minutes or more.

My Role

I designed and developed the end-to-end machine learning pipeline, including data generation, feature engineering, model development, evaluation, and deployment.

The project focused not only on predictive performance but also on creating a solution that could support operational decision-making in a realistic laboratory environment.

Approach

To simulate realistic laboratory conditions, I generated 350,000 synthetic experiments representing equipment degradation, occupancy patterns, scheduling congestion, and reagent variability.

I engineered operational features that reflected the information available before an experiment started, ensuring the model could be used in a real-world decision-making scenario without data leakage.

Three machine learning models were evaluated:

  • Logistic Regression
  • Random Forest
  • HistGradientBoosting

The final model was selected based on PR-AUC performance and calibrated to produce reliable risk scores.

Solution

The final solution combined predictive analytics with an interactive Streamlit application that allows users to:

  • Predict delay risk for individual experiments
  • Analyze operational patterns
  • Run batch predictions on future experiments
  • Review model explanations and risk drivers

Results

PR-AUC: 0.883

F1 Score: 0.798

Risk predictions generated using only information available at booking time.

Interactive dashboard created for operational teams.

Key Takeaway

The most valuable lesson from this project was learning that successful machine learning systems are not only about achieving strong model performance.

They must be designed around operational realities, stakeholder needs, and decision-making workflows.

Building useful AI means understanding the business context as deeply as the technical solution itself.
