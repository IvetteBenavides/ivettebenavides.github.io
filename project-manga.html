Manga — Retail Cloud Data Platform

Designing a scalable AWS architecture to support analytics, AI, and enterprise data operations.

The Challenge

The organization operated multiple disconnected data environments, resulting in duplicated work, inconsistent reporting, and limited analytical capabilities.

My Role

I was responsible for translating business requirements into a cloud architecture capable of supporting future analytics and AI initiatives.

Architecture

  • Amazon MSK (Kafka)
  • Apache Flink
  • S3 + Apache Iceberg
  • SageMaker
  • Bedrock
  • Terraform

Solution

The proposed architecture consolidated data pipelines into a scalable lakehouse model while supporting governance, analytics, machine learning, and AI services.

Key Takeaway

Cloud architecture decisions are business decisions as much as technical ones, requiring trade-offs between cost, flexibility, scalability, and vendor lock-in.
